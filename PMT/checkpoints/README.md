# PMT-iFAN Checkpoints

This directory contains the seven inference-only PMT-iFAN checkpoints. Each
`*_inference.pth` file is paired with the YAML file of the same name under
`../configs/`.

Keep the released filenames unchanged to allow `predict.py` and
`run_validation.py` to discover checkpoints automatically. See
[`../README.md`](../README.md) for prediction and evaluation instructions.
